# Adarsh Tripathi — Portfolio

Personal portfolio website for Adarsh Tripathi, B.E. CSE student at Chitkara University. A clean, minimal single-page site — Nova-inspired structure (hero, numbered services, about, FAQ, contact) built as original plain HTML/CSS/JS, no build step and no external images.

**Live:** https://adarshtripathi108.github.io/portfolio/

## Structure

- `index.html` — the whole site: nav, hero, Selected work, What I do, About, Achievements, FAQ, Contact footer
- `css/style.css` — all styles (white + near-black ink + indigo `#2563EB` accent, responsive)
- `js/main.js` — mobile nav, smooth scroll, footer year, FAQ accordion, scroll reveal
- `favicon.svg` — "AT" monogram favicon
- `404.html` — simple not-found page
- `.nojekyll` — tells GitHub Pages to serve files as-is

## Run locally

No build step — open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000/
