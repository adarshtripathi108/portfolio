JavaQuest

An interactive Java study site, built topic by topic.

J

JavaQuest turns my Programming in Java course (26CS021) into a study site you can actually use: 16 topics, each with explanations, examples and a quiz, plus sub-topics and 50–60 important questions on completion.

It is gamified the way I wanted to study — seasons with locked progression, coins for finishing a topic, and a daily streak. A Question Bank holds 186 LeetCode-style practice problems with topic and difficulty filters.

Every part shipped as its own commit: 211 commits in total, from the first topic page to the last practice problem.
