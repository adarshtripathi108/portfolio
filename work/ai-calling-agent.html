AI Calling Agent

A basic AI calling agent, built from code — for real learning.

A

This project is deliberately built the slow way: from code, in Python, one small feature per commit — no sign-in-and-prompt shortcut. The point is to understand how a calling agent actually works, not just to demo one.

The environment is set up (Python, virtual environment) and the first commit is in. Next steps are a small health-check service, then the call flow itself, each landing as its own staged commit.
