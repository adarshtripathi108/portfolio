KOFFA

A 3D cafe demo website, built to pitch local cafés.

K

KOFFA is a demo-first project: before approaching any local café, I built a complete sample site so owners can see what a 3D website actually looks like. A 3D coffee-cup hero, a filterable menu with &rupee; prices, a WhatsApp order drawer and a book-a-table form.

The content is swappable — the same build can be re-skinned for any café with its own menu, prices and branding. The public demo link is not published yet.
